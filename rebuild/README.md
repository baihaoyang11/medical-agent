# 从零重建：七步搭出一个 RAG 检索层

这个目录不是项目的一部分，是**给项目做的一次反向拆解**。

主项目有 40 个提交、111 个测试、三套评测。但代码是长出来的，
很多"为什么这么设计"藏在了 commit 里。这个目录把它倒过来：

> 从一行代码都没有开始，一层一层加，每加一层就跑一次，看它到底改变了什么。

每步都能单独运行，都输出和上一步的对比。**七步加起来不到 600 行。**

---

## 七步，每步解决一个具体问题

| 步 | 加了什么 | 解决了什么 | 结果 |
|---|---|---|---|
| 1 | 数字面重合 | 先有个能跑的东西 | R@5 **0.760** |
| 2 | 向量 | 口语问法连不上正文 | R@5 **0.990**（+0.23） |
| 3 | BM25 + RRF | 药名、指标这类要靠字面 | 混合 **0.969**，比纯向量**低** |
| 4 | 重排 | 对的那条排得靠前 | **持平**，激进重排还会崩到 0.833 |
| 5 | 路由 | 不同问题需要不同数量的资料 | 召回不变，上下文**省 40%** |
| 6 | 质量门 | 找不到的时候别硬答 | 能挡住 83% 的域外问题 |
| 7 | 汇总 | 哪几层真的在起作用 | 见下 |

---

## 合起来看，只有一个结论是硬的

```
1. 字面重叠          R@5 0.760   MRR 0.627
2. 纯向量            R@5 0.990   MRR 0.897   ← 唯一一次真正的跃迁
3a. 混合（等权）      R@5 0.969   MRR 0.799   ← 反而更低
3b. 混合（偏向量）    R@5 0.979   MRR 0.845   ← 追平，仍不如
4. 向量 + 重排        R@5 0.990   MRR 0.896   ← 持平
```

**从「数词」到「懂语义」是唯一一次大跳跃，后面的层全是微调，有几层还是在拖后腿。**

这不是实现写坏了。这是这套数据的真实结论 —— 而且和主项目里跑 136 段语料、
120 条 query 得到的结论一致（纯向量 0.974，混合 0.905）。

---

## 每一步都留下了一个"为什么"

**第 1 步 → 2：为什么必须换向量**

口语问法「血糖高的人跑步有用吗」和正文「运动治疗应循序渐进」几乎不共享一个字。
数字面无论怎么数都连不上。这不是实现问题，是方法的天花板。

**第 2 步 → 3：为什么加了一层反而更差**

RRF 的隐含假设是「两路质量相当」。实测 BM25 在口语上只有 0.479，
等权融合等于往干净水里兑浑水。**调权重能追平，但追平不等于更好。**

**第 3 步 → 4：为什么重排会开倒车**

用「数词」的标准去改「懂语义」的排序，等于让更聪明的结果听更笨的意见。
把原排序保留一半（`w_orig=0.5`）就不掉了 —— 这就是 `config.RERANK_WEIGHT` 在调的东西。

**第 4 步 → 5：路由的价值不在准确率**

统一给 8 条和按类型给 2~8 条，召回都是 1.000，但平均段数从 8.0 降到 4.8。
**路由省的是钱，不是准确率。** 但分类器只有 34% 一致率、57% 兜底 ——
理论收益拿不到，所以主项目里它默认关闭。

**第 5 步 → 6：什么叫"该说不知道"**

能答的问题相似度 0.52~0.84，答不了的 0.39~0.65，**中间是重叠的**。
单一阈值能把 99% 该答的留下、83% 不该答的挡住，但样本只有 6 条，
而且换个模型这个阈值立刻失效。

## 怎么跑

```bash
python -m rebuild.step1_literal     # 字面匹配
python -m rebuild.step2_vector      # 换向量
python -m rebuild.step3_hybrid      # 混合检索 + 权重扫描
python -m rebuild.step4_rerank      # 重排
python -m rebuild.step5_route       # 路由
python -m rebuild.step6_quality     # 质量门
python -m rebuild.step7_summary     # 全部汇总
```

或者一次跑完：

```bash
python tasks.py rebuild
```

**不需要 API Key。** 向量用本地 `bge-small-zh`（和主项目评测同一套），
语料和评测集直接复用 `eval/`，所以数字可以和主项目对照。

---

## 和主项目的关系

这个目录是**教学复盘**，不是生产代码：

- 生产在 `agents/`、`skills/`、`core/`，这个目录不进主流程，也不被测试覆盖
- 这里刻意写得短、写得直白，生产代码里那些防御性的兜底、降级、重试都省掉了
- 语料和评测集是**复用**的（`eval/knowledge.py`、`eval/filler.py`），不是另造一份 ——
  换个语料，所有数字都要重来，对照就没意义了

一句话：**主项目是"做了什么"，这个目录是"为什么非得这么做"。**
