# 🎨 医学RAG问答系统 - 前端界面

聊天式问答界面，用于展示检索到的证据与答案生成过程。

---

## 📁 文件结构

```
frontend/
├── index.html      # 主页面
├── styles.css      # 样式文件
├── script.js       # 交互脚本
└── README.md       # 本文档
```

---

## 🚀 快速开始

### 步骤1：启动后端服务

**打开第一个终端窗口：**

```bash
cd <项目根目录>
python tasks.py serve
```

等待看到类似以下输出：
```
INFO:     Started server process
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8103
```

### 步骤2：打开前端页面

**方法1：直接双击打开**
- 找到 `frontend/index.html` 文件
- 双击打开（会在默认浏览器中打开）

**方法2：使用浏览器打开**
1. 打开任意浏览器（Chrome、Edge、Firefox等）
2. 按 `Ctrl + O`（Windows）或 `Cmd + O`（Mac）
3. 选择 `frontend/index.html` 文件

**方法3：使用本地服务器（推荐）**

如果遇到跨域问题，可以使用简单的 HTTP 服务器：

```bash
cd frontend
python -m http.server 8000
```

然后在浏览器打开：`http://localhost:8000`

## 🔧 配置说明

### 修改 API 地址

如果后端服务地址不是 `http://localhost:8103`，需要修改 `script.js`：

```javascript
// 找到这一行（第2行）
const API_BASE_URL = 'http://localhost:8103';

// 修改为你的实际地址，例如：
const API_BASE_URL = 'http://192.168.1.100:8103';
```

### 调整界面颜色

在 `styles.css` 的 `:root` 部分修改颜色变量：

```css
:root {
    --primary-color: #4a90e2;      /* 主色调 */
    --secondary-color: #357abd;    /* 辅助色 */
    --success-color: #52c41a;      /* 成功色 */
    /* ... 其他颜色 */
}
```

## ❓ 常见问题

### 1. 页面打开后显示"未连接"

**原因**：后端服务未启动

**解决方法**：
```bash
# 确保后端服务正在运行
cd <项目根目录>
python tasks.py serve
```

### 2. 提示"CORS错误"或"跨域问题"

**原因**：浏览器安全限制

**解决方法**：使用本地服务器
```bash
cd frontend
python -m http.server 8000
# 然后访问 http://localhost:8000
```

### 3. 发送消息后没有响应

**检查清单**：
- ✅ 后端服务是否正常运行
- ✅ API 地址是否正确（`http://localhost:8103`）
- ✅ 浏览器控制台是否有错误信息（按 F12 查看）

### 4. 界面样式显示异常

**原因**：CSS 文件路径错误

**解决方法**：确保 `index.html`、`styles.css`、`script.js` 在同一目录下
